## 1. 系统概述

### 1.1 产品定位
ClipBox 是一个现代化、跨平台、高颜值的剪切板收集与流转工作台，定位为开发者和创作者的 HUD（抬头显示器）工具，而非传统的笔记本或静态相册。

### 1.2 核心设计原则
1. **极致简单**: 零配置，默认即最优，拒绝复杂脚本和配置
2. **顶格颜值**: 现代化 UI，深色模式，磨砂玻璃特效，丝滑动画
3. **真·跨平台**: Linux First，Windows/macOS/Linux 统一体验

### 1.3 技术愿景
通过 **Rust 生态** 构建高性能、内存安全、真正跨平台的桌面应用，确保在 Linux (X11/Wayland)、Windows、macOS 上拥有原生级性能和体验。

## 2. 技术选型与跨平台策略

### 2.1 核心技术栈

#### 2.1.1 后端：Rust (Tauri v2)
**选型理由**：
- **跨平台原生支持**: 单一代码库支持 Windows/macOS/Linux
- **内存安全**: 零成本抽象，无 GC，适合长期后台运行
- **高性能 I/O**: 异步运行时 (Tokio) 处理剪切板监听、文件 I/O、OCR 任务
- **系统级集成**: 通过 Tauri 直接调用 OS API，无需 Electron 的 Node.js 层

**关键依赖**：
```toml
[dependencies]
tauri = "2.0"                    # 跨平台窗口管理和 IPC
tokio = { version = "1", features = ["full"] }  # 异步运行时
sqlx = { version = "0.7", features = ["sqlite", "runtime-tokio"] }  # 数据库
arboard = "3.3"                  # 跨平台剪切板访问
serde = { version = "1", features = ["derive"] }  # 序列化
uuid = { version = "1", features = ["v4"] }       # ID 生成
image = "0.24"                   # 图片处理
```

#### 2.1.2 前端：React + TypeScript
**选型理由**：
- **生态成熟**: 丰富的 UI 组件库和动画库
- **类型安全**: TypeScript 确保前后端接口一致性
- **现代化 UI**: Tailwind CSS + Shadcn/UI + Framer Motion

**关键依赖**：
```json
{
  "dependencies": {
    "react": "^18.2.0",
    "typescript": "^5.0.0",
    "tailwindcss": "^3.3.0",
    "@radix-ui/react-*": "latest",  // Shadcn/UI 基础
    "framer-motion": "^10.0.0",     // 动画引擎
    "@tauri-apps/api": "^2.0.0"     // Tauri 前端 API
  }
}
```

#### 2.1.3 数据库：SQLite (via SQLx)
**选型理由**：
- **本地优先**: 无需网络，数据主权在用户手中
- **跨平台**: 单文件数据库，易于备份和迁移
- **异步支持**: SQLx 提供编译时 SQL 检查和异步查询

#### 2.2.2 平台特定实现

**Linux 支持 (X11/Wayland)**：
```rust
// src-tauri/src/platform/linux.rs
#[cfg(target_os = "linux")]
pub mod linux {
    use x11_clipboard::Clipboard;
    use wayland_client::protocol::wl_seat;

    pub struct LinuxClipboard {
        x11_clipboard: Option<Clipboard>,
        wayland_clipboard: Option<WaylandClipboard>,
    }

    impl LinuxClipboard {
        pub fn new() -> Self {
            // 自动检测 X11 或 Wayland
            if std::env::var("WAYLAND_DISPLAY").is_ok() {
                Self::init_wayland()
            } else {
                Self::init_x11()
            }
        }
    }
}
```

**Windows 支持**：
```rust
// src-tauri/src/platform/windows.rs

pub mod windows {
```

## 4. 数据流设计

### 4.1 采集流程 (Capture Flow)

```rust
// 伪代码示例
async fn handle_clipboard_change(content: ClipboardContent) -> Result<()> {
    // 1. 去重检查
    let hash = calculate_hash(&content);
    if repository.exists_by_hash(&hash).await? {
        return Ok(()); // 已存在，跳过
    }

    // 2. 上下文注入
    let metadata = platform::get_active_window_info()?;

    // 3. 创建 Item
    let item = ClipboardItem {
        id: Uuid::new_v4().to_string(),
        type_: content.get_type(),
        content: content.to_string(),
        original_content: content.to_string(),
        metadata: serde_json::to_value(metadata)?,
        created_at: now(),
        ..Default::default()
    };

    // 4. 同步保存（快速返回）
    repository.insert(&item).await?;

    // 5. 通知前端
    emit_event("clipboard:new", &item)?;

    // 6. 异步处理（不阻塞）
    tokio::spawn(async move {
        if item.type_ == "image" {
            image_processor.generate_thumbnail(&item).await;
            ocr_service.recognize(&item).await;
        }
    });

    Ok(())
}
```

### 4.2 搜索流程 (Search Flow)

```rust
async fn search_items(query: &str) -> Result<Vec<ClipboardItem>> {
    // 混合搜索：content + ocr_text + tags + user_note
    let sql = r#"
        SELECT * FROM clipbox_items
        WHERE is_deleted = 0
        AND (
            content LIKE ?1
            OR ocr_text LIKE ?1
            OR tags LIKE ?1
            OR user_note LIKE ?1
        )
        ORDER BY updated_at DESC
        LIMIT 50
    "#;

    let pattern = format!("%{}%", query);
    sqlx::query_as::<_, ClipboardItem>(sql)
        .bind(&pattern)
        .fetch_all(&pool)
        .await
}
```

## 5. 性能与安全考虑

### 5.1 性能优化策略

#### 5.1.1 异步管道
- **原则**: 所有重型操作必须异步执行，不阻塞主线程
- **实现**: Tokio 异步运行时 + Channel 通信

```rust
// 异步任务队列
pub struct AsyncTaskQueue {
    tx: mpsc::Sender<Task>,
}

impl AsyncTaskQueue {
    pub fn spawn_ocr_task(&self, item_id: String, image_path: String) {
        let tx = self.tx.clone();
        tokio::spawn(async move {
            let result = ocr::recognize(&image_path).await;
            tx.send(Task::UpdateOCR { item_id, result }).await;
        });
    }
}
```

#### 5.1.2 图片存储策略
- **禁止**: 图片 BLOB 存入 SQLite（会导致数据库膨胀）
- **方案**: 文件系统存储 + 数据库存路径
- **目录结构**:
```
~/.clipbox/
├── data/
│   └── clipbox.db
├── images/
│   ├── raw/
│   │   └── {uuid}.png
│   └── thumbs/
│       └── {uuid}_thumb.png
└── config/
    └── settings.json
```

#### 5.1.3 数据库索引
```sql
-- 全文搜索索引
CREATE INDEX idx_search ON clipbox_items(content, ocr_text, user_note);

-- LRU 排序索引
CREATE INDEX idx_updated ON clipbox_items(updated_at DESC);

-- 类型过滤索引
CREATE INDEX idx_type ON clipbox_items(type, is_deleted);
```

### 5.2 安全考虑

#### 5.2.1 数据隔离
- **原则**: 用户数据完全本地化，不上传云端
- **实现**: SQLite 文件权限设置为 600 (仅用户可读写)

#### 5.2.2 输入验证
```rust
// 防止 SQL 注入
pub async fn search(&self, query: &str) -> Result<Vec<Item>> {
    // 使用参数化查询，SQLx 自动转义
    sqlx::query_as("SELECT * FROM items WHERE content LIKE ?")
        .bind(format!("%{}%", query))
        .fetch_all(&self.pool)
        .await
}
```

#### 5.2.3 文件路径安全
```rust
// 防止路径遍历攻击
pub fn validate_image_path(path: &str) -> Result<PathBuf> {
    let base = get_images_dir();
    let full_path = base.join(path);

    // 确保路径在 images 目录内
    if !full_path.starts_with(&base) {
        return Err(Error::InvalidPath);
    }

    Ok(full_path)
}
```

## 7. 部署与构建

```bash

cargo tauri build --target x86_64-apple-darwin
```
