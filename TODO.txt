# 角色设定
你是一位资深的 UI/UX 设计师和前端工程师。

# 任务目标
请重构“搜集箱 (Collection Box)”的界面（也就是卡片右侧）。目前正常不点击详情的时候， 它是一个普通的垂直列表，看起来比较枯燥。
我要你把它改造成一个现代化的**瀑布流卡片布局 (Masonry / Waterfall Grid)**，类似 Pinterest 或 Bento Grid 的风格。

# 设计要求（请自由发挥创意）
1. **布局策略：**
   - 不要用死板的单列列表，改用多列瀑布流布局。
   - 卡片的高度应该根据内容自动适应（文字多的卡片长一点 但是不要太长，图片卡片大一点），减少空白间隙。宽度可以适当窄一点。能展示的差不多就好。 
   - 最上面保留工具栏（工具栏对所有卡片都有效， 选中了后移到工具栏做事情 ---看看放哪儿美观吧）

2. **卡片视觉风格：**
   - 风格要干净、清爽。使用白色背景、圆角（Rounded-xl）和轻微的阴影。
   - 边框要极细、极淡，让卡片看起来像是“浮”在画布上的纸片。

3. **交互动效（微交互）：**
   - 鼠标悬停（Hover）在卡片上时，卡片要有一个平滑的“上浮”动画（Translate Y），阴影加深。
   - 边框颜色可以变成主题色（比如绿色），给用户明确的反馈。
   - 整个过程要丝滑、有触感。

4. **智能内容展示（重点）：**
   - **文件/文件夹：** 不要只显示一行枯燥的文件路径字符串。
     - 请设计一个**图形化**的展示方式。如果是文件， 可以显示一个大大的文件类型图标（PDF、Word、文件夹图标等），下面优雅地显示文件名。
   - **图片：** 直接展示图片缩略图，保持视觉冲击力。
   - **长文本：** 像便利贴一样展示，如果太长可以优雅地截断。
