  1. 统一样式系统，先降“样式债”                                                                                                                                                                              
                                                                                                                                                                                                             
  - 问题：当前样式层有明显叠加和覆盖竞争，维护成本高。                                                                                                                                                       
  - 证据：workspace.css 2724 行 + polish.css 889 行 + titlebar.css 354 行。                                                                                                                                  
  - 建议：建立“组件样式归属边界 + token 白名单”，逐步去硬编码色值/时长。                                                                                                                                     
  - 参考：workspace.css (/D:/code/qollect/src/styles/workspace.css) polish.css (/D:/code/qollect/src/styles/polish.css) titlebar.css (/D:/code/qollect/src/styles/titlebar.css)                              

  2. 减少硬编码颜色与过渡，彻底改为语义 token                                                                                                                                                                
                                                                                                                                                                                                             
  - 问题：虽然你已经开始 token 化，但仍有大量 rgba(...)、#ff...、0.15s ease 分散存在，主题一致性不稳。                                                                                                       
  - 建议：状态色只走 --state-*，动效只走 --motion-* + --ease-*，lint 阶段禁止新增硬编码。                                                                                                                    

  5. 搜索区与收藏区做“交互一致性协议”

  - 问题：SearchBar 与 CollectionPanel 都有过滤器，但行为细节和反馈风格仍有微差。
  - 建议：抽统一 Filter primitives（type/date/tag/saved-view），共享状态视觉和键盘语义。
  - 参考：SearchBar.jsx (/D:/code/qollect/src/components/SearchBar.jsx) CollectionPanel.jsx (/D:/code/qollect/src/components/Panel/CollectionPanel.jsx)

  6. 时间轴可继续“弱轴强化卡”

  - 你已经改好了很多，但还可进一步：轴线只在组边界明显，行内仅保留点位与轻微 hover 响应。
  - 目标：用户第一眼看卡片内容，不是看结构线。
  - 参考：polish.css (/D:/code/qollect/src/styles/polish.css)

  - 你已做 first-use 很好；下一步建议每种空状态都给“下一步最高价值动作”。
