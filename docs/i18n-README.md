# 国际化快速开始

## 切换语言

### 方法 1：标题栏快速切换
点击窗口标题栏右上角的 🌐 按钮，即可在中英文之间快速切换。

### 方法 2：设置页面
1. 点击右上角的 ⚙️ 设置按钮
2. 选择"通用设置"标签
3. 在"语言"下拉框中选择你想要的语言
4. 点击"保存"

## 支持的语言

- 🇨🇳 简体中文 (zh-CN) - 默认
- 🇺🇸 English (en-US)
