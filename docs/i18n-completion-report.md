## 🚀 使用方法

### 用户端
1. 点击标题栏的 🌐 按钮快速切换语言
2. 或在 设置 → 通用设置 中选择语言
3. 语言选择自动保存，重启后生效

### 开发端
```jsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t, i18n } = useTranslation();

  return (
    <div>
      <h1>{t('app.title')}</h1>
      <button onClick={() => i18n.changeLanguage('en-US')}>
        Switch Language
      </button>
    </div>
  );
}
```
