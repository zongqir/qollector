## 使用方法

### 用户视角
1. 点击标题栏的 🌐 按钮快速切换语言
2. 或在设置 → 通用设置中选择语言
3. 语言选择会自动保存，下次启动时生效

### 开发者视角
```jsx
// 在组件中使用翻译
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t, i18n } = useTranslation();

  return (
    <div>
      <h1>{t('app.title')}</h1>
      <button onClick={() => i18n.changeLanguage('en-US')}>
        Switch to English
      </button>
    </div>
  );
}
```

## 扩展新语言

### 步骤
1. 在 `src/i18n/locales/` 创建新的 JSON 文件（如 `ja-JP.json`）
2. 复制 `en-US.json` 的结构，翻译所有文本
3. 在 `src/i18n/index.js` 中注册新语言
4. 在 `src/Settings.jsx` 的语言选择器中添加选项
