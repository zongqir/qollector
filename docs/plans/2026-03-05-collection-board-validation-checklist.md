# 收藏区回归验收清单（2026-03-05）

## 1. 范围

本清单用于验证以下改动在收藏区（Collection / Favorites）是否稳定：

1. 顶部筛选在收藏流真实生效：搜索 / 类型 / 日期 / 暂存。
2. 收藏卡片主操作收敛为 3 个：`暂存`、`收藏`、`换颜色`。
3. 其他动作通过右键菜单触发。
4. 标签可控性增强：标签搜索、标签计数、清空标签筛选。
5. 窄窗与键盘可访问性增强：`420` 断点、焦点样式、键盘菜单。

## 2. 验收前准备

1. 启动：`npm run tauri dev`（或仅前端 `npm run dev`）。
2. 准备数据：至少包含 `text/link/file/image/code` 各 1 条收藏数据。
3. 保证至少有：
   - 一个带多个标签的收藏项。
   - 一个已暂存（is_pinned）的收藏项。
   - 一个已自定义底色的收藏项。
4. 语言分别切到 `zh-CN` 和 `en-US` 验证。

## 3. 尺寸矩阵（必测）

| 尺寸 | 模式 | 语言 | 必测断言 |
| --- | --- | --- | --- |
| 320x450 | mini | zh-CN / en-US | 顶部不挤压；按钮可点；卡片操作区不换行错位；右键菜单不溢出 |
| 375x667 | mini | zh-CN / en-US | 标签搜索输入可用；tag rail 可横向滚动；卡片可键盘聚焦 |
| 560x700 | normal | zh-CN / en-US | `@container 560` 降级生效；meta 行可换行不重叠 |
| 800x600 | normal | zh-CN / en-US | 卡片/列表切换正常；右键菜单动作完整；筛选结果正确 |

## 4. 行为检查项

### 4.1 筛选契约

1. 收藏模式下输入顶部搜索词，结果数量变化且仅展示匹配收藏项。
2. 切换类型筛选（含 `code`），结果与类型一致。
3. 选择日期范围后，收藏流结果按 `created_at` 过滤。
4. 启用“仅暂存”后，仅展示 `is_pinned=true` 的收藏项。

### 4.2 卡片主操作与右键菜单

1. 卡片头部仅显示 3 个主操作：`暂存`、`收藏`、`换颜色`。
2. 复制/打开/编辑/删除等动作通过右键菜单可用。
3. 收藏模式下右键菜单中 `暂存/收藏` 处于次级视觉层级（不抢主注意力）。
4. 右键菜单 `Delete` 二次确认生效。

### 4.3 标签能力

1. 标签搜索输入关键词后，tag chip 列表按关键词过滤。
2. 每个标签显示数量徽标，数量与数据一致。
3. 已选标签数量提示正确。
4. “清空标签筛选”后恢复全部标签结果。

### 4.4 可访问性与键盘

1. `Tab` 可聚焦到收藏卡片，焦点边框清晰可见。
2. 卡片聚焦后 `Enter / Space` 能打开预览。
3. 卡片聚焦后 `Shift+F10` 或 `ContextMenu` 键能打开菜单。
4. 按钮 / 标签 / chip 在键盘焦点下均有 `focus-visible` 反馈。

### 4.5 视觉与布局

1. `420` 以下断点：toolbar 纵向降级，不出现输入框被裁切。
2. 标签编辑器在窄窗可完整输入，不被按钮挤压。
3. 颜色选择浮层不被裁切，可正常关闭（点击外部关闭）。
4. 中英文长文本（如按钮/提示文案）不出现逐字竖排。
