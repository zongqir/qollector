# 三分区 UI 回归清单（mini + 正常）

日期：2026-03-08
范围：历史流 / 收藏区 / 工作区
目标：每次改动后，快速验证“视觉一致性 + 状态一致性 + 交互连续性”。

## 固定尺寸

- `320x450`（mini）
- `375x667`
- `560x700`
- `800x600`

## 历史流

1. 基础阅读
- 卡片头部结构为：类型图标 + 时间/来源 + 状态点（pin/favorite）。
- hover 或键盘聚焦时，工具条显隐节奏一致，无跳闪。

2. 状态面板
- 加载态显示统一 `state-panel` 风格。
- 搜索中显示统一 `state-panel` 风格。
- 后端失败显示错误态与重试按钮，点击可重新请求。

3. mini 检查
- `320x450` 下重试按钮全宽可点。
- 卡片标签和备注不出现逐字竖排或重叠。

## 收藏区

1. 卡片一致性
- 与历史流/工作区同语法：类型图标 + 元信息 + 状态点。
- DnD 与非 DnD 两种模式视觉一致。

2. 状态面板
- 首次加载、筛选中、筛选无结果、后端错误都可区分。
- 后端筛选失败不是静默回退，必须可见错误提示与重试。

3. 交互细节
- 顶部标签轨道筛选、清空筛选、提示条不挤压。
- 颜色选择器弹层不遮挡关键按钮，点击外部可关闭。

## 工作区

1. 卡片一致性
- 头部结构与历史流/收藏区一致。
- 收藏状态 chip 与 favorite 语义一致（`is_favorite`）。

2. 状态面板
- 空态、筛选空态、后端错误态风格统一。
- 后端失败且仍有列表内容时，顶部有轻量错误反馈。

3. 交互与动效
- hover/聚焦的工具按钮显隐平滑。
- 卡片 hover 与 focus ring 节奏和历史流、收藏区一致。

## 语义与数据链路

1. 命名语义
- `pin` 只对应 workbench。
- `favorite` 只对应 collection。

2. 筛选语义
- 主筛选走后端链路，前端只做展示级过滤。
- 后端失败必须给出可见反馈，不可静默吞错。

## 触控可用性（新增）

1. 命中面积
- `pointer: coarse` 下，历史流/收藏区/工作区关键按钮命中面积不低于约 `24px`，重试/主操作按钮不低于约 `34px` 高度。
- 不允许出现“仅 hover 才能看到且无法触发”的关键操作。

2. 小窗密度
- `320x450` 与 `560x700` 下，卡片操作按钮不裁切、不重叠、不溢出容器边界。
- 工具条按钮显隐与键盘聚焦行为一致，触控端默认可见关键操作。

## 快速结论模板

- 尺寸：`320x450 / 375x667 / 560x700 / 800x600`
- 历史流：`通过 / 不通过`（问题点）
- 收藏区：`通过 / 不通过`（问题点）
- 工作区：`通过 / 不通过`（问题点）
- 结论：`可合并 / 需修复后复测`

## 本轮已收口项（2026-03-08）

- 收藏区卡片渲染已合并为单一函数，DND 与非 DND 分支不再重复维护。
- 历史流/收藏区/工作区卡片 footer 密度已统一：
  - 备注默认 `2` 行，mini `1` 行，收藏列表模式 `1` 行。
  - 标签默认字号与间距统一，溢出仍显示 `+N`。
- 主要交互样式中的 `transition: all` 已清理为明确属性过渡，降低抖动与性能噪音。
- 三分区卡片正文行距已收口到统一 token（`--card-content-line-height`），并同步压齐工作区卡片头/正文底部留白，减少视图切换时的密度跳变。
- 顶部筛选 rail 到主内容区的纵向间距已统一到 token（`--panel-rail-content-gap`），历史流/收藏区/工作区的“筛选 -> 列表”过渡节奏一致。
- 顶部筛选控件（搜索/切换/筛选触发器）已统一接入 `top-rail` token（高度/圆角/焦点环/控件间距），三分区顶部工具语法一致。
- mini 与窄窗下顶部控件密度已统一：图标类控件按 `top-rail-mini-control-height` 收口，文本类控件按 `top-rail-mini-pill-height` 收口，降低 `320x450` 拥挤感。
- 筛选弹层（tag/date/type/saved-view）已统一 `dropdown` token，并增加短窗 `max-height` 保护，避免 mini 高度下弹层裁切与滚动区过长。
- 超窄宽度下触发器文案已按策略自动收敛：历史流隐藏非核心状态条与长徽标，收藏区/工作区的排序与清理按钮自动图标化，优先保留搜索与主内容。
- 历史流顶部第二行状态已从多条并行提示合并为单条摘要状态（可一键清理），收藏区提示仅在“相关上下文”出现，降低常驻视觉噪音。
- 收藏区提示区进一步收敛为“可展开提示入口”：默认常驻只保留数量/筛选状态/错误反馈，帮助文案改为按需展开，mini 与窄窗下不再挤压首屏信息。
- 三分区顶部摘要语法已统一：历史流摘要补齐类型/收藏/工作台筛选信号，收藏区补齐关键词/类型/日期/仅工作台摘要，工作区新增独立摘要行（数量 + 生效筛选 + 错误反馈 + 一键清理）。
- 三分区摘要条已抽成共享组件（`PanelSummaryRow`），历史流新增关键词与结果数摘要且可一键全清，收藏区/工作区改为同一组件渲染，后续迭代可避免样式与语义漂移。
- 三分区卡片骨架已语义统一（`panel-card-*`）：历史流/收藏区/工作区的 header/meta/state/actions/body/footer 接入同一类名与 token 基线，历史流工具条按钮改为与收藏区/工作区同风格边框按钮，减少跨分区视觉跳变。
- 三分区卡片内容模板已统一：`text/link/files/image` 与 `note/tags` 接入共享 `panel-card-content-*` 与 `panel-card-tag*` 语义类，通用样式下沉到 `theme.css`，降低跨分区内容块视觉割裂。
- 三分区顶栏层次已重绘为“粘性玻璃轨道”：历史流搜索栏、收藏区标签轨道、工作区筛选轨道统一接入玻璃背景/边框/阴影 token，正常模式强化层次，mini 模式自动降级去除重玻璃效果。
- 三分区卡片操作条显隐策略已统一为同一套规则（`panel-card-actions--hover-reveal`）：桌面端默认简洁、hover/focus/选中时显露，触控端默认可达，避免“某区可见某区不可见”的体验割裂。
- 历史流卡片工具区密度已收口：移除固定宽工具区，操作胶囊按内容自适应，缩窄窗口时不再出现明显空洞留白。
- mini 与窄窗顶部轨道再次降噪：历史流搜索轨道与工作区筛选轨道改为轻量 mini 轨道 token（弱阴影/弱边框/无重 blur），降低 `320x450` 下的压迫感。
- 状态反馈补齐到“有内容时也可见”：历史流顶部摘要新增后台筛选中/失败提示；收藏区与工作区摘要在列表不为空时也会显示“筛选中”徽标与失败反馈，降低“卡住但无提示”的误判。
- 三分区空态/错误态/加载态已接入统一状态模板（`panel-state-*`）：标题层级、辅助文案与按钮尺寸一致；`320x450` 与窄窗下按钮区统一单列全宽，避免“能看见但难点击”。
