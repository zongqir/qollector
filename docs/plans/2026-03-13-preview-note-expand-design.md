# 预览区备注展开与专注态设计

日期：2026-03-13

## 背景

当前预览区备注虽然已经支持预览展开，但在空间紧张时，标签区、正文区、meta 与工具栏会继续占据大量高度，导致长备注展开后仍然不够从容，用户的注意力也会被其他信息打断。

## 目标

1. 让长备注在预览区可读，不强迫用户立即进入编辑。
2. 在 mini 模式或紧凑窗口下，允许展开备注进入“备注专注态”，让备注成为当前唯一重点。
3. 在空间充足时保持普通展开，不强制进入专注态。
4. 不影响列表卡片里的紧凑备注样式。

## 方案

- 仅在预览区备注组件启用 `preview` 变体。
- 默认展示 2 行备注预览。
- 如果备注内容超过 2 行，显示 `展开 / 收起` 按钮。
- 备注正文保持只读可复制，不再点击正文直接进入编辑。
- `编辑备注` 作为独立动作保留。
- 点击 `展开 / 收起` 只切换查看状态，不进入编辑。
- 当备注在普通展开下仍然不够看，且预览区空间确实紧张时，展开备注或进入备注编辑会触发“备注专注态”：
  - 隐藏标签区、正文区、meta 与底部工具栏。
  - 保留顶部导航，避免完全失去上下文。
  - 备注区域获得更大的可用高度，展开内容在备注区内部滚动。
- 当备注在普通展开下已经足够展示，或预览区空间充足时，展开备注仅做普通展开，不进入专注态。

## 范围

- 本次只修改预览区备注显示层与预览区布局切换逻辑。
- 不改备注保存逻辑、不改工作区内联编辑器、不改历史卡片 footer 的备注样式。

## 验收点

1. 短备注保持紧凑，不出现多余操作。
2. 长备注默认显示两行，并可展开查看。
3. 只有在“普通展开仍不够 + 当前空间紧张”时，展开备注后才进入备注专注态。
4. 在空间充足时，展开后保持普通布局，不额外切换专注态。
5. 展开后仍然可以收起，收起后恢复原布局。
6. 查看与编辑语义分离，备注正文不因单击而误入编辑态。
